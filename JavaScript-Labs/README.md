## Ba Lab

### Lab 08 — JavaScript 1: Language Foundations

Thực hành liên kết JavaScript nội bộ/bên ngoài, Console và `noscript`; built-in objects; arrays, functions và objects. Có đủ Exercise 8.1–8.11.

**Truy cập:** [Mở Lab 08](lap8/index.html)

### Lab 09 — JavaScript 2: DOM and Events

Thực hành chọn và cập nhật DOM, quan hệ node, tạo/xóa phần tử, event listeners, sự kiện load, debugging, form và validation. Có đủ Exercise 9.1–9.8.

**Truy cập:** [Mở Lab 09](lap9/index.html)

### Lab 10 — JavaScript 3: jQuery

Thực hành jQuery selectors, DOM manipulation, event handlers, effects/animation và AJAX đọc JSON. Bài 10.9–10.10 cần mở qua máy chủ HTTP hoặc GitHub Pages; trình duyệt thường chặn AJAX khi mở bằng `file://`.

**Truy cập:** [Mở Lab 10](lap10/index.html)

## Hướng dẫn truy cập bài thực hành

1. Mở `index.html` để xem trang cá nhân và chọn Lab 08, 09 hoặc 10.
2. Trong mỗi Lab, mở `index.html` riêng để xem danh sách bài và chọn Exercise/Walkthrough.
3. Các trang tĩnh có thể mở trực tiếp trong trình duyệt. Với Lab 10 bài AJAX, chạy qua GitHub Pages hoặc một máy chủ localhost.
4. Với bài yêu cầu Console, hover/click, breakpoint hoặc form, thực hiện tương tác trong trình duyệt để quan sát kết quả. Ảnh minh chứng thao tác trình duyệt do sinh viên tự chụp khi làm báo cáo.

## Kiến thức đạt được

- **Lab 08:** nền tảng ngôn ngữ JavaScript, hàm, phạm vi biến, arrays và objects.
- **Lab 09:** chọn/cập nhật DOM, tạo event listeners, xử lý biểu mẫu và debugging.
- **Lab 10:** dùng jQuery cho selectors, DOM, events, effects và AJAX.

Trang chủ có phần tự đánh giá kết quả học tập và giới thiệu vai trò của JavaScript trong ứng dụng web thương mại điện tử.

Hai file rỗng `css/style.css` và `js/main.js` ở cấp này đã được xóa; các thư mục `css/` và `js/` hiện không có file.
